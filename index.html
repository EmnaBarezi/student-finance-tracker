Student Finance Tracker

About

Purpose

Track student spending, set a monthly budget cap, search with regex, and view a 7-day chart. Data is saved in your browser via localStorage.

Features

  • Add, edit, and delete transactions
  • Sort by description, amount, category, or date
  • Live regex search with match highlighting
  • Monthly budget bar with ARIA live alerts
  • 7-day spending chart
  • JSON import and export with validation
  • Multi-currency: USD, EUR, GBP
  • Custom categories in Settings

Regex Catalog

RulePatternCatches
Description/^\S(?:.*\S)?$|^\S$/Leading or trailing spaces
Amount/^(0|[1-9]\d*)(\.\d{1,2})?$/Invalid numbers, too many decimals
Date/^\d{4}-(0[1-9]|1[0-2])-(0[1-9]|[12]\d|3[01])$/Wrong date format
Category name/^[A-Za-z]+(?:[ -][A-Za-z]+)*$/Numbers, symbols, double spaces
Duplicate words (back-reference)/\b(\w+)\s+\1\b/i"the the", "my my"

Keyboard Map

  • Tab - move between all interactive elements
  • Enter / Space - activate buttons and nav
  • Escape - close any open dialog
  • Skip link - first Tab press jumps to main content
